# 欧几里得算法：

欧几里得算法主要应用在求最大公约数(gcd)时的过程进一步简化，其定义为:
$$
\vee a,b \in \mathbb{N},b \neq 0 \Longrightarrow gcd(a,b) = gcd(b,a\ mod\ b)
$$
也许大多数人在学的过程中并未在意为什么这个定理能够成立，那么现在来证明一下：

>考虑两种情况，分别为 $b < a$ 和 $b\ge a$.
>
>第一种情况好想，因为 $b > a$ ,所以 $a mod b = a,gcd(b,a)\ =\ gcd(a,b)$.
>
>第二种情况,蓝书上提供了一种证明方法，不过这里不用蓝书的方法，使用反证法:
>
>假设两者的gcd不相等，那么现在设 $g = gcd(a,b),g_1 = gcd(b,a\ mod\ b)$ ,且 $g_1 > g$.
>因为 $a\ mod\ b$ 可以表示为 $a - \left \lfloor \frac{a}{b}  \right \rfloor \cdot b$ 的形式，所以
>根据同余定理，可得出 $ a\mid g_1$ 的结论.
>
>所以我们能从第二个式子得到 $a,b\mid g_1$ 的结论，由于 $g$ 的定义，$g_1$ 绝对不可能大于 $g$ ，又由于其定义
>也是最大公约数，所以我们最后得出了 $g = g_1$ 的结论，欧几里得算法也就证明出来了.

看一下gcd的模板代码：
```cpp
int gcd(int a,int b){
    if(b == 0) return a; //已找到最大公约数
    else return gcd(b,a % b); //否则继续找
}
```
## 补-更相减损术:
定义：
$$
\vee a,b \in \mathbb{N},a\ge b \Longrightarrow gcd(a,b) = gcd(b,a - b) = gcd(a,a - b)
$$ 
对于任意a,b的公约数d，满足 $d\mid a,d\mid b$. 那么根据同余定理，一定满足 $d\mid (a - b)$.
相反，也满足 $d\mid (b - a)$ ,因此对于任意的公约数都成立这个条件，包括最大公约数，因此这个结论证明完成.

$$
gcd(x,a_0) = a_1
$$
$$
lcm(x,b_0) = b_1 
$$
