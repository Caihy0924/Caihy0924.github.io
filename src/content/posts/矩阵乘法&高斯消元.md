# 矩阵乘法:

重要条件：第一个矩阵的列数必须等于第二个矩阵的行数！

1.2 计算公式
$$C_{i,j} = \sum_{k=1}^{m} A_{i,k} \times B_{k,j}$$

通俗理解：结果矩阵第 $i$ 行第 $j$ 列的元素，等于 $A$ 的第 $i$ 行与 $B$ 的第 $j$ 列对应元素相乘再求和。

二、矩阵乘法的性质
2.1 基本性质
性质	公式	说明
结合律	$(AB)C = A(BC)$	可以改变计算顺序
分配律	$A(B+C) = AB + AC$	对加法可分配
数乘结合	$(kA)B = A(kB) = k(AB)$	数乘可以提到外面
不满足交换律	$AB \neq BA$	⚠️ 重要！顺序不能随便换
2.2 特殊矩阵
单位矩阵 $I$：对角线为 1，其余为 0，满足 $AI = IA = A$
零矩阵 $O$：所有元素为 0，满足 $AO = OA = O$
转置矩阵 $A^T$：行列互换，满足 $(AB)^T = B^T A^T$
三、基础代码实现
3.1 朴素算法 $O(n^3)$
# include<bits/stdc++.h>
using namespace std;

const int MAXN = 105;
int n, m, p;
int a[MAXN][MAXN], b[MAXN][MAXN], c[MAXN][MAXN];

int main() {
    // 输入矩阵 A (n×m) 和 B (m×p)
    cin >> n >> m >> p;
    
    for(int i = 1; i <= n; i++)
        for(int j = 1; j <= m; j++)
            cin >> a[i][j];
    
    for(int i = 1; i <= m; i++)
        for(int j = 1; j <= p; j++)
            cin >> b[i][j];
    
    // 矩阵乘法核心代码
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= p; j++) {
            for(int k = 1; k <= m; k++) {
                c[i][j] += a[i][k] * b[k][j];
            }
        }
    }
    
    // 输出结果矩阵 C (n×p)
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= p; j++)
            cout << c[i][j] << " ";
        cout << "\n";
    }
    
    return 0;
}
3.2 代码解析
三层循环的含义：

外层 i：遍历结果矩阵的行
中层 j：遍历结果矩阵的列
内层 k：计算点积（行×列）
时间复杂度：$O(n \times m \times p)$，当三个维度相等时为 $O(n^3)$

空间复杂度：$O(n^2 + m^2 + n \times p)$

四、矩阵快速幂
矩阵乘法最重要的应用之一就是矩阵快速幂，可以在 $O(n^3 \log k)$ 的时间内计算 $A^k$。

4.1 原理
利用快速幂的思想：

如果 $k$ 是偶数：$A^k = (A^{k/2})^2$
如果 $k$ 是奇数：$A^k = A^{k-1} \times A$
4.2 代码实现
# include<bits/stdc++.h>
# define int long long
using namespace std;

const int MOD = 1e9 + 7;
const int MAXN = 105;
int n;

struct Matrix {
    int mat[MAXN][MAXN];
    
    Matrix() {
        memset(mat, 0, sizeof(mat));
    }
    
    // 矩阵乘法
    Matrix operator*(const Matrix &b) const {
        Matrix c;
        for(int i = 1; i <= n; i++) {
            for(int k = 1; k <= n; k++) {
                if(mat[i][k] == 0) continue;  // 小优化
                for(int j = 1; j <= n; j++) {
                    c.mat[i][j] = (c.mat[i][j] + mat[i][k] * b.mat[k][j]) % MOD;
                }
            }
        }
        return c;
    }
};

// 矩阵快速幂
Matrix qpow(Matrix a, int b) {
    Matrix res;
    // 初始化为单位矩阵
    for(int i = 1; i <= n; i++)
        res.mat[i][i] = 1;
    
    while(b > 0) {
        if(b & 1) res = res * a;
        a = a * a;
        b >>= 1;
    }
    return res;
}

signed main() {
    cin >> n;
    int k;
    cin >> k;
    
    Matrix a;
    for(int i = 1; i <= n; i++)
        for(int j = 1; j <= n; j++)
            cin >> a.mat[i][j];
    
    Matrix res = qpow(a, k);
    
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= n; j++)
            cout << res.mat[i][j] << " ";
        cout << "\n";
    }
    
    return 0;
}
4.3 优化技巧
循环顺序优化：i-k-j 顺序比 i-j-k 更快（更好的缓存局部性）
跳过零元素：if(mat[i][k] == 0) continue;
取模优化：可以在最后统一取模（注意溢出）
五、经典应用
5.1 斐波那契数列
用矩阵快速幂可以在 $O(\log n)$ 时间内求第 $n$ 项斐波那契数。

转移矩阵：
$$\begin{bmatrix} F_{n+1} \ F_n \end{bmatrix} = \begin{bmatrix} 1 & 1 \ 1 & 0 \end{bmatrix} \times \begin{bmatrix} F_n \ F_{n-1} \end{bmatrix}$$

// 求第 n 项斐波那契数
int fib(int n) {
    if(n <= 1) return n;
    
    Matrix base;
    base.mat[1][1] = 1; base.mat[1][2] = 1;
    base.mat[2][1] = 1; base.mat[2][2] = 0;
    
    base = qpow(base, n - 1);
    return base.mat[1][1];  // F_n
}
5.2 图上路径计数
给定一个有向图，求从点 $i$ 到点 $j$ 恰好经过 $k$ 条边的路径数。

解法：邻接矩阵的 $k$ 次幂，$A^k[i][j]$ 就是答案。

5.3 动态规划优化
当 DP 转移是线性递推时，可以用矩阵快速幂优化。

典型题目：

洛谷 P1962 斐波那契数列
洛谷 P3390 矩阵快速幂
POJ 3070 Fibonacci
六、进阶优化
6.1 Strassen 算法
对于大矩阵，Strassen 算法可以将复杂度优化到 $O(n^{\log_2 7}) \approx O(n^{2.81})$。

核心思想：将矩阵分块，用 7 次乘法代替 8 次乘法。

6.2 稀疏矩阵优化
当矩阵中有很多 0 时，可以用稀疏矩阵存储（只存非零元素），大幅减少计算量。

七、模板总结
// 完整的矩阵快速幂模板
# include<bits/stdc++.h>
# define int long long
using namespace std;

const int MOD = 1e9 + 7;
const int N = 105;
int n;

struct Matrix {
    int a[N][N];
    Matrix() { memset(a, 0, sizeof(a)); }
    
    Matrix operator*(const Matrix &b) const {
        Matrix c;
        for(int i = 1; i <= n; i++)
            for(int k = 1; k <= n; k++)
                if(a[i][k])
                    for(int j = 1; j <= n; j++)
                        c.a[i][j] = (c.a[i][j] + a[i][k] * b.a[k][j]) % MOD;
        return c;
    }
};

Matrix qpow(Matrix x, int y) {
    Matrix res;
    for(int i = 1; i <= n; i++) res.a[i][i] = 1;
    while(y) {
        if(y & 1) res = res * x;
        x = x * x;
        y >>= 1;
    }
    return res;
}
